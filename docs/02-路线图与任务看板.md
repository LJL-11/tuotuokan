## 已知技术债（别踩坑）

- 误差指标的训练集/测试集必须**同分布带噪**，否则泛化差距恒负、过拟合造不出来。
- 多项式基用 `t = 2x - 1`，`x^k` 在 `[0,1]` 上高阶几乎不振荡。
- 正则项要按矩阵尺度归一化，否则 `logLam` 拖动不敏感。
- `file://` 下不能用 ES module / `fetch` 本地文件；保持传统 script 标签。
- 随机数必须走 `TTK.math.rng(seed)`，禁止 `Math.random()`，否则拖动时图形抖动。
- `TTK.generator` 未配置 `endpoint` 时，`generate()` 同步返回 `ai:false` 的本地草稿；页面会明示
  「不是 AI 生成」「刷新不保留」。服务端 `POST /v1/generate` 已实现；11-09 付已配置真实供应商
  （阿里云百炼 `deepseek-v4.1-flash-1017`，`TTK_LLM_THINKING=off`）并完成端到端验收 13/13（真实
  `dsl.prompt` 走完整 HTTP 链路）与稳定性批测 9/10（成功耗时 2.8–4.3s）。模型偶发保留名违规时
  客户端重试一次，仍失败则诚实降级草稿。配好代理后模型模板会落盘并在刷新后恢复，草稿仍不落盘。
- GitHub Pages 只托管静态文件，**不会运行 `services/api/server.js`**；跨设备同步必须另跑 / 部署 Node 服务，
  否则各设备数据始终独立。默认不部署是刻意的「本地优先」口径，见 `README.md`。
- **能力口径（#20 冻结方案）**：本机只读「文字 / 文件名 / 图片内嵌文字」，不识别画面内容、不转写语音；
  **语音只认文件名，请改用文字，或把概念写进文件名**。图片与语音字节不上传。
  对外演示不得宣称能识别图片内容或转写语音，界面、README、`docs/01`、`docs/02`、`docs/04` 口径一致。
