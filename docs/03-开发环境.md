# 开发环境

## 最快路径：什么都不装

**双击仓库根目录的 `index.html`** 就能运行完整原型（10 个精修概念 + 四视图）。纯 HTML/CSS/JS，无构建、无后端、无 npm 依赖，
`file://` 协议下可用。这是刻意的设计（见 `adr/0001-为什么不用构建工具.md`），演示时不用现场装环境。

> 因为走 `file://`，所有脚本用传统 `<script src>` 标签按顺序加载，**不要改成 ES module、不要引入打包器**，
> 否则本地会被 CORS 拦下白屏。

## 校验与可选后端需要 Node

```bash
node -v            # 需要 >= 18，用于校验和可选的同步服务，运行静态页面不需要
npm test           # 等价于 node tools/verify.js：语法 / 路径 / DOM 引用 / 数值 / DSL / 表达式安全
npm run check:anon # 匿名合规扫描
npm run check      # 原有校验 + API / 数据层验收 + 匿名合规扫描
```

项目 `package.json` 里 `private: true` 且没有 `dependencies`，**不需要 `npm install`**。

## 可选：运行匿名同步服务

需要测试跨设备同步时，在仓库根目录运行 `npm run api`。默认 API 地址为
`http://127.0.0.1:8787/v1`，由 `services/api/server.js` 读取以下环境变量：

| 环境变量 | 默认值 | 用途 |
|---|---|---|
| `PORT` | `8787` | HTTP 服务监听端口 |
| `HOST` | `127.0.0.1` | 监听地址；默认仅接受本机连接，按实际运行环境调整 |
| `TTK_DB_DIR` | 仓库内 `services/api/.data/` | 数据保存目录，实际文件为目录下的 `db.json`；相对路径按启动进程的工作目录解析，建议配置绝对路径 |

PowerShell 示例（在仓库根目录执行，变量仅作用于当前终端会话及其子进程）：

```powershell
$env:PORT = '8787'
$env:HOST = '127.0.0.1'
$env:TTK_DB_DIR = 'D:\tuotuokan-data'
npm run api
```

服务在首次保存数据时自动创建目录。默认 `.data/` 已被 Git 忽略；自定义数据目录同样不要提交进仓库。
同一个数据目录只运行一个服务进程，保留该目录即可保留已同步的记录。

页面端通过 `TTK.data.remote.configure('http://127.0.0.1:8787/v1')` 显式连接服务，
服务端环境变量不会自动修改页面配置。更多接入与验收说明见
[`services/api/README.md`](../services/api/README.md)。

**线上地址**：<https://ljl-11.github.io/tuotuokan/>（I12 已完成，网页 #8 已关闭）。
GitHub Pages 仅托管静态页面，**不运行 `services/api/server.js`，也不保存学习数据**；发布由仓库 Settings
配置 `main / root`，push 后自动更新，无需额外部署工作流；public 仓库下没有到期日。
后端服务的单独部署是可选增强，目前不部署：各设备记录彼此独立，交接靠导出 / 导入匿名 JSON，
口径见 `README.md` 的「部署与数据：本地优先」。

## 常见开发动作

### 新增一个精修概念模板
1. 在 `src/model/templates.js` 末尾按现有结构加一条，返回统一 `ComputeResult`（见 `docs/01`）。
2. 放进 `TTK.templates` 数组；填 `prerequisites` 让图谱能连边。
3. `npm test`：CI 会遍历默认参数与每个参数极值，检查 NaN / 非法坐标，并采样检查挑战可达。
4. 浏览器里拖一遍，确认指标卡与洞察文案对得上。

### 用 DSL 加一个模板（不改源码）
```js
var spec = JSON.parse(...);                  // 例如 contracts/examples/spring.json
var v = TTK.dsl.validate(spec, engine.all().map(function (t) { return t.id; }));
if (!v.ok) console.error(v.errors);
var tpl = TTK.dsl.compile(spec, v);
engine.register(tpl); engine.select(tpl.id);
```
公式里 `x` 是横轴，`p.<key>` 取参数，`m.v0` 是第一个指标；可用 `Math.*` 白名单函数、`PI`、四则、`^`、比较、三元。

### 生成沙盒（姜的 #I4，已完成）
`TTK.dsl.prompt(conceptText)` 提供系统提示；`TTK.generator.generate()` / `mount()` 已实现输出校验、失败重试与本地降级。
模型输出必须 `TTK.dsl.validate()` → `TTK.dsl.compile()` → `engine.register()`，**不许直接把模型输出当代码执行**。
要真正走模型，先用 `TTK.generator.configure({ endpoint, model })` 配到服务端代理；仓库目前还没有 `/generate` 实现
（网页偿还 Issue #19 归秦），密钥不许放进前端。未配置时返回 `ai:false` 的 `dsl.draft()` 草稿，UI 明示「不是 AI 生成」。

**输入能力口径**：本机只读「文字 / 文件名 / 图片内嵌文字」，**语音只认文件名，请改用文字，
或把概念写进文件名**；不识别画面内容、不转写语音，字节不上传。

```js
TTK.generator.config();                 // -> {enabled, endpoint, model}，不含密钥
TTK.generator.recognize('过拟合');      // -> {ok, conceptId, level, source, message, ...}
TTK.generator.generate('阻尼共振', { ids: engine.all().map(function (t) { return t.id; }) });
TTK.settings.readGenConfig();           // -> {endpoint, model}，本机设置
TTK.settings.saveGenConfig({ endpoint: '', model: '' });  // 清空即回本地草稿模式
```

**界面入口（付已补齐）**：「学习记录」抽屉 → 「AI 生成代理（可选）」，可填 `POST /generate` 地址与模型名，
存 `ttk.generator.v1`（不进轨迹 / 同步队列 / 导出 JSON），刷新后自动恢复；清空回本地模式、零网络请求。
模型模板（`mount().persist === true`）写入 `ttk.custom.v1` 并在启动时恢复，本地草稿不落盘；
「学习报告」与「模板工坊」共用同一组导出 / 导入入口，导入后立即挂回引擎。

### 接同步服务（秦的 #I10 / #I11，数据侧已完成；可选）
```js
TTK.data.remote.configure('https://<your-api>/v1');   // 传空字符串回到纯本地模式
```
端点定义见 `services/api/openapi.yaml`。上层只认 `TTK.data`，换适配器不改 UI / 图谱 / 报告。
**界面入口已完成（#I15）**：打开「学习记录」抽屉 → 「跨设备同步（可选）」，可填服务地址、查看 / 输入
16 位匿名 ID、看待上传数与最近错误、点「立即同步」或「恢复本地模式」；配置写入 `ttk.remote.v1`，刷新后保留。
控制台入口 `TTK.data.remote.configure(...)` 依然可用。
**不配置就是纯本地模式**：数据只在这台设备这个浏览器里，不发任何网络请求，也不会自动合并到别的设备。
要在设备间交接，也可以在「学习报告」视图点「导出匿名 JSON」，到另一台设备点「导入 JSON」（等价于
`TTK.data.exportAll(engine)` / `importAll(文本)`）。

### 导出真实试用数据（复赛验证材料）
```js
var json = TTK.data.exportAll(engine);   // 匿名，符合 learning-trace.schema.json
```
导出前先跑 `npm run check:anon`。

## 踩过的坑

| 现象 | 原因 / 处理 |
|---|---|
| 本地白屏、控制台 CORS 报错 | 用了 ES module 或 `fetch` 本地文件；改回 script 标签 |
| 拖参数时曲线乱抖 | 模板里用了 `Math.random()`；换成 `TTK.math.rng(seed)` |
| 画布模糊 | 按 `devicePixelRatio` 缩放，渲染器已处理，别重复缩放 |
| 隐私模式下记录失效 | `TTK.data` 已 try/catch 静默降级，属预期行为 |
| 过拟合怎么拖都出不来 | 训练/测试集必须同分布带噪；多项式基用 `t=2x-1`；正则按矩阵尺度归一化 |
| 公式写 `window.alert(1)` 被拒 | 预期行为，受限求值器在编译前拒绝任意全局访问 |
