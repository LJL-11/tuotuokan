## 已交付

- Node 零依赖 HTTP 服务：匿名身份、事件上报、轨迹导入导出、自定义模板读写和健康检查。
- 使用仓库现有 JSON Schema 校验事件、轨迹与模板，字段错误返回路径；不执行模板公式。
- 服务端按身份去重，通过临时文件原子替换保存；保存失败返回 500，重试不会重复增加事件。
- 客户端按服务 URL 与匿名 ID 保存缓存及待上传队列；断网刷新后恢复，成功确认后才出队。
- 网络错误、超时、5xx、429、408 退避重试；其他 4xx 保留队列并报告原因，不丢弃整批记录。
- 后台通过现有 `/trace/import` 合并进度、卡点与模板，再读取 `/trace` 更新缓存并通知订阅者。
- 身份 / 服务切换时隔离缓存与队列，忽略旧请求的响应和错误；清空记录后不再从旧版键恢复历史。
- `npm run check` 和 CI 均包含新增 API / 数据层验收。

## 实现边界

- 服务使用单进程 JSON 文件存储，同一个目录不可运行多个服务进程；不是多实例数据库。
- 匿名 ID 当前即访问凭证，尚无正式账号认证。浏览器需支持安全随机数。
- 进度按逻辑 OR 合并，卡点与事件去重，同 id 模板以最后一次成功上传为准；不支持远端删除、实时推送或自动轮询。
- `clear()` 仅清空本机并关闭同步，远端历史保留；已送达请求不可撤回。
- 浏览器存储配额不足时只能保留当前会话数据，并通过 `storageError` 提示；此时不能承诺刷新后恢复。
- I11 的产品入口 / 跨设备体验和 I12 的部署仍待后续完成。
